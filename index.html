FAQ

Good questions. Short answers.

What do I need to run OnlyMacApp?

A Mac running macOS 14 or later. It's a native SwiftUI app, so it feels like it belongs there.

Is it a subscription?

No. $19.99 once and it's yours.

Do my files get uploaded anywhere?

No. Everything runs on your Mac. Download Video is the one tool that touches the internet, fetching only the link you paste.

Do I need to install FFmpeg?

Video and audio tools use FFmpeg if it's installed (brew install ffmpeg); the app tells you when it's missing. PDF, image, OCR and rename tools need nothing extra.

What does "Rewrite PDF" do?

It re-saves your PDF with PDFKit. Pages and text are preserved; file size may stay the same or shrink — we don't promise compression.

macOS says "unidentified developer" when I open it. Is that normal?

Yes, for now. On first launch, right-click the app and choose Open, then confirm. This is a one-time step per Mac while we complete Apple Developer certification — the app itself is fully functional and safe.
